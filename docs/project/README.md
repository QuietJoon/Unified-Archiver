# Project Records

This directory contains planning, intake, gap-tracking, and implementation-status material used during development of `unified-archive`.

These files are primarily maintainer records. They may describe:

- in-flight work that was later completed before `v0.1.0`
- deferred items tracked during development rather than current release blockers
- historical scope discussions that are not the public user contract

For the current release-facing documentation, use:

- [`README.md`](../../README.md)
- [`docs/USER_MANUAL.md`](../USER_MANUAL.md)
- [`docs/API_REFERENCE.md`](../API_REFERENCE.md)
- [`Limitations.md`](../../Limitations.md)
- [`CHANGELOG.md`](../../CHANGELOG.md)

Read this directory when you want implementation history or internal planning context, not when you need the current supported-workflow summary.
