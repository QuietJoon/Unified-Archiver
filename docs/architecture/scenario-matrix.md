## SFX Detection Scenarios

> **Note:** No `Confirmed` detection path currently exists in the implementation. Every *positive* detection returns `probable()` (`SfxConfidence::Probable`); rejections return `not_sfx()` (`SfxConfidence::NotSfx`). The `SfxConfidence` tri-state (`NotSfx`/`Probable`/`Confirmed`) retains the `Confirmed` variant for future use when higher-confidence heuristics are added. Confidence is an **enum, not a float** — the "~0.9" figure that used to appear in these rows was removed from the code with the `f32` field (I3, R0001-0080).

> **Detection mechanics (R0001-0080).** `detect_sfx` does one read of the first 1 MiB (plus a small probe tail), classifies the first 4 KiB of that buffer as the stub, then scans the 1 MiB window for archive signatures. Stub classification is **in-crate, header-fields only** — a newline-terminated shebang line for `ScriptInterpreter`, and prefix/identification-header checks for ELF, PE, and Mach-O. `goblin` is **not** a dependency of this crate and never appears in `Cargo.toml`; its whole-file parsers could not classify a truncated 4 KiB stub prefix and were replaced by the header-field checks (R0079-0010). The `Integrations` column below reflects that: SFX detection integrates with no external parser.
